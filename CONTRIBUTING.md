# Contributing to Flappy Poop

Thank you for wanting to help.

- **Reports are always welcome.** A bug, a confusing screen or an idea: open an issue with the
  forms under "New issue". A quiz card that looks wrong: tap the 🚩 beside its code in the game,
  which fills in the card for you.
- **Code, art and card changes from outside need a contributor agreement first.** Flappy Poop is
  licensed by its author (see [`LICENSE`](LICENSE) and [`LICENSE-CONTENT.md`](LICENSE-CONTENT.md)),
  and the author must be able to relicense it later, for example to a non-profit. So before a pull
  request can be merged, its author signs a short agreement granting that right. Open an issue to
  ask for it before you start on anything large.
- **Never post personal data** in an issue or a pull request: no real names of players, no player
  ids, no user codes, no screenshots that show them.

How the code is laid out and the rules it follows are in [`AGENTS.md`](AGENTS.md).
