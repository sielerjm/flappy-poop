# Plan: Mandarin (Simplified) + language picker
- Created: 2026-11-02
- Status: complete
- Baseline: v0.2.6 on `main` (+ HUD probiotic commit before i18n)

## Goal
In-game UI in English and Simplified Chinese. Globe button next to info opens a Language overlay. Persist locale; first run follows `navigator.language` when nothing is stored. Ship TRANSLATION_NOTES.md for LLM review.

## Decisions
- Language **overlay** (not tray toggle) for discoverability.
- Tray glyph **🌐** to match emoji chrome.
- `keydown-L` opens Language.
- Phaser `useAdvancedWrap: true` on wrapped text (CJK has no spaces).
- Small CJK lines at **14px** (not 12px).
- `normalizeSettings` gets an explicit `locale` branch (boolean loop is not enough).
- Brand **Flappy Poop** stays Latin; glossary Fiber/Probiotic/Bacteria → 纤维 / 益生菌 / 有害细菌; Silent mode → 静音模式.
- HUD probiotic resize committed separately; iOS sound keeper left unstaged.

## Result
Shipped as `0.2.7`. Catalog in `src/i18n.js`; review handoff in `TRANSLATION_NOTES.md`.

Manual-only: How to play wrap in 中文; 14px meta lines; 🌐 / L picker; reload keeps locale; mid-run Language pauses.
