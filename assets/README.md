# Assets — the art contract

Gameplay sprites are listed below. `npm test` checks that the sizes in this table match the PNG files, so if you change a size, update this table and the scene code that positions it.

The player and items are Michael's drawings. Put a new source PNG in `assets/src/` and run `uv run --with pillow python3 tools/process_art.py` (or any Python with Pillow) to crop, knock out **background** white (not eyes or mouths), and write the 192×192 contract files (an animated GIF becomes a one-row spritesheet of 192×192 frames). With `oxipng` installed (`brew install oxipng`) the script also recompresses every PNG losslessly (`-o 4 --strip safe`); without it, Pillow's optimized save is kept. The poop set (alive, dead, stink1, stink2, falling, stink-falling1, stink-falling2, scared, stink-scared1, stink-scared2, fart) shares one body scale and is cut around the body centre, so texture swaps never move the body; the fart frame's body is found with a brown-pixel mask because its cloud sits to the left. The game draws them at 0.5 scale (96 logical px on the 720×1280 field): the art is exported at 2x the size it is drawn at, not 4x (plan 35, 2.1), so a 3x-DPR phone still gets more texture pixels than screen pixels at a quarter of the decoded memory. Keep new art at 2x its drawn size; `tests/assets.test.js` checks it. Do not list source files in this table.

`pipe.png`, `villi.png`, and `ground.png` are still placeholders from `tools/make_placeholders.py`. That script must **not** overwrite `poop.png` or the icons. The icons are cut from `assets/src/FlappyPoopAppArt.png` by `process_art.py` (`process_icons`). Browsers cache favicons and manifest icons by URL for a long time, so every icon link in `index.html` and `manifest.webmanifest` carries the same `?v=N`; bump it whenever the icon art changes (`tests/assets.test.js` keeps the tags equal).

## Background layers (art contract)

The background is a **solid colour per level** (`LEVEL_COLORS` in `src/config.js`, cycling, softened by `levels.whiteBlend`, crossfaded between levels at the break) with one or more **transparent PNG overlay layers** on top. Each layer is a `tileSprite` listed in `BACKGROUND.layers` (`key`, `parallax`) and scrolls at its own fraction of the pipe speed (villi 0.25). Pipes, items, the poop and the two strips draw above all layers; the ceiling strip (top 128 px) and the ground strip (bottom 128 px) are separate tileSprites in front of the pipes at full pipe speed (`ceilingHeight` / `groundHeight`), and each hides that part of every layer. The poop dies at either strip's edge and the pipe gap keeps `gapMargin` inside both.

- `villi.png`: 720×1280, PNG with alpha, exactly the portrait playfield (it is scaled to the screen height, never tiled vertically). On a wider desktop field the same 720 px copy repeats sideways (tile scale `FIELD.minWidth / width`), as does `ground.png`, so a seam at the wrap would show there first. Transparent wherever the level colour should show; a cream mucosa backdrop from each screen edge to `BAR_FRAC` (85 %) of the shortest fringe tip's reach, solid, with its lumen edge feathered to transparent over the last `BACKDROP_FADE` (5 %, about 8 px) of its depth (behind the strips and the fringes, so the level colour shows only from the backdrop's edge to the lumen and no tip lines up with the bar), and where the villi are. Both ends show a back fringe (in this overlay) behind a front row (`ceiling.png` / `ground.png`, mirrors of each other with the same seed, their cream lines ending at `BAR_FRAC` of the shortest front tip too). Every finger's rounded far end is off the image edge (the strips' front rows) or behind a strip (the fringes), so the walls read as villi running off-screen, not teeth; `villi_band(min_frac)` enforces the minimum length. The lumen-side tips undulate along x on a sine with a whole number of periods per 720 px tile (`BACK_WAVE` ±24 px on the fringes, `FRONT_WAVE` ±8 px on the strips, inside their 16 px `TIP_ZONE`), plus a little per-finger jitter. Must tile horizontally: the right edge continues into the left (the placeholder draws 40 px past each side and wraps). A 2× version (1440×2560) is fine; keep each side ≤ 4096 px (phone WebGL limit); the scene scales by `GAME_WIDTH / frame.width`. Keep the fringes clear of the middle ~50 % of the height where the gaps sit (today each end's fringe reaches about 235 px in from the edge, with its far ends behind the strips).
- The same villi show over every level colour (Set2: tan, teal, periwinkle, lime, yellow, light blue). Keep villi away from those hues; `tests/levels.test.js` rejects a level colour that comes within reach of the villi pink or the cream bands, so a redrawn villi colour means re-checking that test's constants.
- Adding a layer: a PNG with the same rules, a row in `BACKGROUND.layers`, a `load.image` in `src/scenes/Boot.js`, and a row in the table above. Nothing in `Play.js` changes.
- The finish line is a generated texture (`src/ui/finish.js`). A drawn one later: `finish.png`, 64×1280, alpha, scrolls with the pipes.
